Anesthesia ITE Trainer: home-screen app

Put every file in this folder at the root of a PUBLIC GitHub repository (free GitHub Pages needs a public repo).

GitHub Pages:
1. github.com > New repository > name it (e.g. anes-ite) > Public > Create.
2. "uploading an existing file" > drag in all files from this folder > Commit.
3. Settings > Pages > Source: Deploy from a branch > Branch: main, folder / (root) > Save.
4. After about a minute: https://YOURNAME.github.io/anes-ite/

Install:
- iPhone/iPad: Safari > Share > Add to Home Screen.
- Android: Chrome > menu > Install app.
Works offline after the first load.

Progress is stored on each device, separately from the ABSITE app. To move it from the artifact or another device:
Stats > Progress and devices > Create code > Copy, then paste in the app > Import. Codes start with ITE1.

Updating: replace index.html and change V in sw.js (anes-ite-v1 to anes-ite-v2).
